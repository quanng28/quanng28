# Quan Nguyen

I'm a second-year computer science student at Drexel University. I came to software from economics, and I learn best with a real problem in front of me.

My first substantial project was an AR furniture app. I started before I understood everything it would take to build it; working through the mistakes taught me how to keep learning while making something useful. I've kept that approach as I've moved into AI applications and developer tools.

## What I've been building

### [GitWhy](https://gitwhy.dev)

My main focus: keeping the context behind AI-assisted code changes. I started it after watching teams use multiple coding agents, then struggle to reconstruct why a change had been made.

I built a Go CLI and MCP server that link recorded decisions to Git commits, with PostgreSQL-backed workspace synchronization and a GitHub App that brings relevant context into pull requests.

### [HaneiRoom Copilot](http://tryhanei.app/)

A furniture-sourcing and client-review platform shaped by conversations with more than 50 U.S. interior designers. It helps designers find products and collect client approvals in one place.

I built a pipeline that turns design preferences into Gemini-generated searches, retrieves products concurrently through SerpAPI, and deduplicates and ranks the results against style and budget.

### [HaneiRoom](https://www.haneiroom.com/)

An iOS app for previewing multiple pieces of furniture together in a room. I built multi-object placement and manipulation with SwiftUI, ARKit, and RealityKit, plus cached loading of furniture models from Firebase.
